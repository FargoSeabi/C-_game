# 🐍 Snake Game in C++

A simple console-based Snake Game built using C++.  
This project demonstrates fundamental programming concepts such as:

- Game loops
- Functions
- Arrays
- Enumerations
- Keyboard input handling
- Basic collision detection

---

## 🎮 Controls

| Key | Action |
|-----|--------|
| W   | Move Up |
| S   | Move Down |
| A   | Move Left |
| D   | Move Right |
| X   | Exit Game |

---

## 🖥️ Requirements

- Windows OS  
- g++ compiler (MinGW recommended)  
- VS Code / Dev-C++ / CodeBlocks  

---

## ⚙️ How to Run

### 1️⃣ Clone the repository

```bash
git clone https://github.com/your-username/Snake-Game-CPP.git
cd Snake-Game-CPP/src
```

### 2️⃣ Compile

```bash
g++ main.cpp -o snake
```

### 3️⃣ Run

```bash
snake
```
